# Eval generation 9 — cost by layer need (2026-08-19)

Design in `questions9.md`: 15 subjects x 3 turns, split into three arms by
which layer the T1 question needs — **layer 1 only** (raw SDE lookup),
**layer 2 only** (fit math on a supplied fit), **both** (lookup feeding fit
math). Every subject then gets:

- **T2** — a follow-up on the same topic (warm context, fits still resident)
- **T3** — an unrelated question in a warm session

T3 is deliberately a *question another arm already answered cold as its T1*,
so the same question is measured twice: once at the start of a session and
once late in one. The L1 arm's T3 is the L2-5 align question; the L2 and both
arms' T3 is the L1-2 blueprint question.

Cost is the deliverable. Answers were read for sanity but not graded against
pinned keys this round.

## Run configuration

- Subjects: sonnet, spawned via the Agent tool (multi-turn needs Agent +
  SendMessage, which **inherits the session's reasoning effort** rather than
  pinning medium the way the workflow orchestrator does — so these numbers sit
  slightly above a true medium-effort product run).
- Stack: eve-fitting MCP + both skills; layer-1 access by raw SQL.
- **The new `eve-sde` MCP server is NOT live in this run.** It is registered
  in `.mcp.json`, but a session reads that file at startup, so these figures
  are the **baseline** the with-server run gets compared against.
